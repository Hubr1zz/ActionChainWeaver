# 四个上手案例

在 Unity 中按顺序打开 `Scenes` 文件夹里的场景，进入 Play Mode，跟着按钮操作即可。右上角可以切换 `中文 / EN`，也可以打开「查看规则」，看看当前场景有哪些 Action 和 Reactor。

| 场景 | 你会看到什么 |
| --- | --- |
| `01_BasicQueue` | 一次攻击被拆成多个步骤；中途失败时，后面的步骤不会执行。 |
| `02_ReactorScopes` | 攻击不同敌人会触发不同效果，例如格挡、反击和回血。 |
| `03_Presentation` | 攻击逻辑和撞击动画分别排队；还可以试试「忙时不接受新输入」。 |
| `04_PreviewAndCommit` | 把攻击牌拖到敌人上先看预计伤害；松手后才真正扣血。 |

核心流程很简单：提交一个 Action → 队列逐步执行 → Reactor 在执行前后响应 → 新效果继续进入队列。动画由独立的表现队列处理；预览只计算可能的结果，不会提前修改游戏状态。

案例 UI 已保存在场景中，可以直接在编辑器里修改。中文字体的授权文件见 [Fonts/OFL.txt](Fonts/OFL.txt)。想了解实现细节，可继续阅读 [ActionQueue 新手简介](../ActionQueue/GETTING_STARTED.md)。
